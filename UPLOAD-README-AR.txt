لوحة التحكم — رفع إلى Vercel
1) ارفع محتويات مجلد admin-dashboard إلى مستودع GitHub مستقل، أو اختر هذا المجلد كـ Root Directory في Vercel.
2) أمر البناء: npm run build
3) أمر التثبيت: npm install (أو npm ci)
4) انسخ متغيرات البيئة المطلوبة من .env.example إلى إعدادات Vercel، ولا تضع أسرار الخادم داخل ملفات الواجهة.
5) إعداد Firebase/R2 الفعلي مطلوب قبل تشغيل البيانات والرفع الحقيقي. راجع README.md و docs إن كانت متاحة في الحزمة الأصلية.
